# Что это?
*Проект ОАЗИС* - система, предназначенная для автоматизации и упрощения записи студентов на курсовые работы и доступа к их списку как у студентов, так и у преподавателей.

Система включает в себя веб-сайт и базу данных.

Проект разрабатывается для кафедры прикладной математики КубГУ с потенциалом для расширения на другие кафедры ФКТиПМ.
# Стадия разработки
Проект близок к завершению работы над основным функционалом.
Ведётся разработка модели курсовых работ в базе данных и методы работы с ними на сайте.
Корректируется внешний вид пользовательского интерфейса.
